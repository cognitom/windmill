# Windmill
Windmill is a keymap for 40% keyboards.

このキー配列は、40%キーボード向けに作成したものです。

- 風車状のカーソル配置
- かな入力対応 (OSのIMEの「かな入力」を使う)
- 親指シフト (タップでSpace、ホールドでShift)
- [Boardsource Technik](https://boardsource.xyz/store/5ffb9b01edd0447f8023fdb2)と YMDK YMD40 v2 用の[ファームウェア](https://github.com/cognitom/windmill/releases)作成済み

## キー配列

4つのレイヤーで構成されています。かな (レイヤー0) と英数 (レイヤー1) がベースレイヤーで、
最下段左端のキーで切り替えます。

### かな入力時 (レイヤー0)

OSのIMEを「かな入力」に設定して使います。ファームウェア側でかなへの変換はせず、
標準のJISかな配置がそのまま出るようにしています。

|  |  |  |  |  |  |  |  |  |  |  |  |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| Esc | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 0 | Enter |
| Tab | Q | W | E | R | T | Y | U | I | O | P | [ |
| BS | A | S | D | F | G | H | J | K | L | ; | ' |
| **英数/かな** | Z | X | C | V | B | N | M | , | . | / | ` |

最下段はホールドで別の役割になります。

| キー | タップ | ホールド |
|--|--|--|
| 左端 | 英数 (2回タップでかな) | Ctrl + 英数レイヤー |
| Z | Z | GUI |
| X | X | Alt |
| C / , | C / , | Fn |
| V / M | V / M | Sym |
| B / N | B / N | Shift |

Shiftを押しながら打つと、一部のキーは別の記号になります (IMEをかな入力にしていると
通常の位置では打てない記号を、ここに逃がしています)。

| キー | W | R | U | [ | K | L | ; | ' | A | O | P |
|--|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| Shift時 | + | \ | - | ] | < | > | ? | _ | Z | 「 | 」 |

親指のShift (B/N) を押しながらそのキー自身をタップすると、半角スペースが入ります。

### 英字入力時 (レイヤー1)

|  |  |  |  |  |  |  |  |  |  |  |  |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| Esc | Q | W | E | R | T | Y | U | I | O | P | Enter |
| Tab | A | S | D | F | G | H | J | K | L | ; | ' |
| BS | Z | X | C | V | B | N | M | , | . | ↑ | → |
| 英数/かな | GUI | Alt | Fn | Sym \ | Space | Space | Sym / | Fn | App | ← | ↓ |

- Esc(✕)とEnter(○)が対称配置
- BSが最左列
- カーソルキーが右下に風車状に並ぶ
- Spaceはホールドで Shift (SandS)

### 記号とファンクションキー

最下段のキーをホールドすると、記号(Sym)またはファンクションキー(Fn)の入力になります。

**Sym (レイヤー2)**

|  |  |  |  |  |  |  |  |  |  |  |  |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 0 | |
| | ! | @ | # | $ | % | ^ | & | * | ( | ) | ` |
| | = | + | - | _ | [ | ] | ~ | { | } | ↑ | → |
| | | | | | \| | ? | | | | ← | ↓ |

**Fn (レイヤー3)**

|  |  |  |  |  |  |  |  |  |  |  |  |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| Win | | | Andr | | | | | | | Boot | 明暗 |
| F1 | F2 | F3 | F4 | F5 | F6 | F7 | F8 | F9 | F10 | F11 | F12 |
| Del | PrtSc | | | | 輝度- | 輝度+ | ミュート | 音量- | 音量+ | ↑ | → |
| | | | | | | | | | | ← | ↓ |

## 追加機能

### かな / 英数 の切り替え

最下段左端のキーで切り替えます。IMEへ英数(`KC_LNG2`)・かな(`KC_LNG1`)を送るのと同時に、
キーボード側のベースレイヤーも合わせて切り替えます。

| 操作 | 動作 |
|--|--|
| 1回タップ | 英数 (レイヤー1へ) |
| 2回タップ | かな (レイヤー0へ) |
| ホールド | Ctrl + 英数レイヤー |

ホールド中は英数レイヤーになるので、かな入力中でも <kbd>Ctrl</kbd>+<kbd>C</kbd> などが
そのまま打てます。

かなのままSymレイヤーの数字・記号を打った場合は、自動的に英数へ切り替えて送出し、
かなへ戻します (全角で入力されるのを防ぐため)。

### ダークモード

デフォルトの状態はLEDが明るいので、暗い部屋で使う場合に光量を落として使えるダークモードを
用意しています。使い方は、次の通り。

- <kbd>Fn</kbd> + <kbd>Enter</kbd> を押す

もう一度押すと解除されます。設定はEEPROMに保存され、USBを挿し直しても保持されます。

なお、10分間操作がないとLEDは消灯します。次の打鍵で点灯し、その打鍵自体は入力されません。

### 「」の出し分け (Windows / Android)

<kbd>Shift</kbd>+<kbd>O</kbd> / <kbd>Shift</kbd>+<kbd>P</kbd> で入力する 「」 は、
OSのIME実装によって必要なキーコードが異なります。<kbd>Fn</kbd> を押しながら最上段の
左端 (Esc の位置 = Win) と左から4番目 (Andr) で切り替えます。設定はEEPROMに保存されます。

Androidで使う場合の注意は[導入方法](docs/install.md)を参照してください。
